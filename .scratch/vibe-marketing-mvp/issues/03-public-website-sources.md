# 03 — Import and curate public website sources

**What to build:** An operator can crawl bounded public pages from submitted domains, inspect the discovered sources, and choose which sources inform the business context.

**Blocked by:** 02 — Complete manual business intake.

**Status:** ready-for-agent

**Implemented in commit:** —

- [ ] Crawling respects robots directives, domain boundaries, and a configured page limit.
- [ ] Authenticated pages are never accessed automatically.
- [ ] Users can include or exclude every discovered source and see its retrieval date.
